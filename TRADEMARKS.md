# Oreja brand and name use

The GPL-3.0-only license covers the source code. It does not grant permission
to use the Oreja name, logo or other brand identifiers to imply official origin,
endorsement or affiliation.

Do not distribute a fork as “official Oreja” or suggest that the Oreja team
supports it. Use a distinct name and logo.

The project makes no claim here that the name is registered. This file states
the project's position on name and endorsement use.
