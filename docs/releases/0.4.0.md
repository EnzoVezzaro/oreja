# Oreja 0.4.0

**Released:** 2026-11-15  
**Minimum macOS:** 14.2  
**Distribution:** ad-hoc signed, not notarized

Oreja 0.4.0 separates interruption sources from playback targets. Apple Music remains available,
and the new experimental Browser target can control standard HTML audio/video through browser
Apple Events scripting.

## What's new

- Choose which apps Oreja listens to independently from which playback targets respond.
- Select all supported browsers or the active browser: Safari, Chrome, Edge, Brave, Arc, and ego lite.
- Choose Pause (resume at the same position) or Lower volume for browser media.
- When “Pause while I speak” is enabled, the selected target responds to the user's speech as well.
- Settings has focused Audio, Playback, Automation, and Privacy sections. Opening Oreja from Finder
  shows Settings for returning users; first-run onboarding remains unchanged.

## Browser support and permissions

Browser control is experimental. It relies on standard HTML media elements and each browser's
JavaScript-from-Apple-Events setting, plus macOS Automation permission. Protected/custom players may
not respond. Firefox has no adapter, Internet Explorer is not available on macOS, and Spotify's
native app is not a playback target.

The maker reported successful real browser playback in their setup. The exact browser, site, and
playback settings were not recorded, so this is not evidence of universal browser or player coverage.
Browser interruption monitoring remains separate and may capture output from all tabs in a selected
browser.
